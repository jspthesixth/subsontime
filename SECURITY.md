# Security

## Reporting a vulnerability

Report it privately through GitHub: on this repository, open Security, then [Report a vulnerability](https://github.com/jspthesixth/subsontime/security/advisories/new). Do not open a public issue.

Include what is affected, how to reproduce it and what an attacker gains. The answer comes in the advisory.

## Scope

- The hosted service at subsontime.com: the addon, the site and the Open Timings API.
- The code in this repository: the server, the Docker image, the `subsontime` command line, the Jellyfin plugin and the Bazarr+ provider.

Subtitle sources and other addons a configuration points at are out of scope. Report those to their owners.

## Supported versions

Only the latest release gets security fixes.
